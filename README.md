# Megnézendő Filmek – Weboldal dokumentáció

A weboldalunk bemutatása!


A weboldalunkon a megnézendő filmeket tudod elmenteni.
A weboldal tartalmaz egy form-ot, amelyben megadhatjuk a hozzáadandó film
- Címét
- Műfaját
- és egy URL által egy képet róla(thumbnail)

A weboldalon amint ezeket kitöltöttük, a hozzáadás gombbal hozzá adhatjuk a listához.
Minden negyedik kártya után csinál egy új sort.
A kártyák törlése tökéletesen, és hiba mentesen működik, a minden kártyában megtalálható "Törlés" gombbal.
