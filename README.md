# Megnézendő Filmek – Weboldal dokumentáció

<p>Ebben az .MD fájlban bemutatjuk a weboldal rengeteg funkcióját.</p>

## A weboldalunk működésének bemutatása!

<p>A weboldalt JS kódjáért Szabolcs felelt.</p>
<p>A weboldalunkon a megnézendő filmeket tudod elmenteni.</p>
<p>A weboldal tartalmaz egy form-ot, amelyben megadhatjuk a hozzáadandó film</p>
<ul>
<li>Címét</li>
<li>Műfaját</li>
<li>és egy URL által egy képet róla (thumbnail)</li>
</ul>
<p>A weboldalon amint ezeket kitöltöttük, a hozzáadás gombbal hozzá adhatjuk a listához.</p>
<p>Minden negyedik kártya után csinál egy új sort.</p>
<p>A kártyák törlése tökéletesen, és hiba mentesen működik, a minden kártyában megtalálható "Törlés" gombbal.</p>
<p>Ezek működését egy JS fájl biztosítja amely az index.html fájlhoz van hozzácsatolva.</p>

## A weboldal kinézete/designja
<p>A weboldal kinézetéért Krisztián és Attila felelt, amely a bootstrap és CSS formázásból áll.</p>
<p>Rengeteg új CSS tag-et és funkciót tartalmaz a weboldal, amit megtanultunk a használatuk közben.</p>
<p>A weboldalon található 2 animáció, amelyet mi csináltunk saját kézzel.</p>
<p>A weboldal letisztult, modern megjelenésű.</p>
